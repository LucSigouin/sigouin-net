# Process as a showpiece

Clients believe what they can see. The best studios do not write a "how we work" essay. They film the floor, the board, the gate, the pick.

Luc already has the raw footage: a CNVS canvas of agent terminals, a 1.6 MB workbench.html ops board, 134 REPORT.md files, GATE-TESTED.txt, and fleet rounds with competing lanes. This note maps how other people show process, then names eight exhibits Luc can cut from files already on disk.

Model this session: grok-4.6.

## How to turn terminals and boards into video

Do this later. This round does not spend credits or record. Tools only.

### asciinema

URL: https://asciinema.org/ and https://docs.asciinema.org/getting-started/

What: records a session to a `.cast` text file. Player is JS. Viewers can copy text out of the replay.

Pros: tiny files, searchable, embeddable, live streams exist. Honest. Looks like a real terminal.

Cons: no cursor chrome, no CNVS window, no browser. Cannot show the canvas, only a pane.

Output: `.cast`, optional gif via `agg`. Use for check-lane.py and worker shells.

### vhs by charmbracelet

URL: https://github.com/charmbracelet/vhs

What: a `.tape` script types into a virtual terminal. Renders gif, mp4, webm, or a PNG frame folder. Needs ttyd and ffmpeg.

Pros: repeatable. Hide setup with `Hide`/`Show`. CI can regenerate. Looks designed, window bar and padding included.

Cons: it is a reconstruction, not the real session. Multi-pane CNVS will not fit. Long fleet runs are a pain to script.

Output: gif / mp4 / webm / png sequence. Use for a 8 s "verify goes green" loop.

### Screen Studio

URL: https://screen.studio/

What: macOS recorder with auto zoom on the cursor. Exports up to 4K 60 fps, gif, hosted links. Webcam optional.

Pros: the only clean way to film the actual CNVS canvas plus the workbench browser node. Auto zoom sells the click on a red row.

Cons: paid Mac app. Files get large. Easy to over-zoom and look like an ad. Do not add a webcam. Luc's rule is almost no text, not a talking head.

Output: mp4, gif. Use for exhibits 1, 4, 5.

### ffmpeg

What: the glue. Cut, scale, loop, poster frame, gif palette.

Pros: free, scriptable, every format.

Cons: not a recorder. You still need a source.

Useful one-liners later, not run this round:

```
ffmpeg -i in.mp4 -an -vf "scale=1280:-2,fps=12" -loop 0 out.gif
ffmpeg -i in.mp4 -ss 0 -vframes 1 poster.jpg
ffmpeg -i in.mp4 -c:v libvpx-vp9 -b:v 0 -crf 32 -an out.webm
```

Keep autoplay loops under 3 MB. Webm first, mp4 fallback, poster jpg.

### Lottie

What: After Effects to JSON. Play, pause, seek. Weak state machines.

Pros: everywhere, small-ish, designers already know AE.

Cons: playback, not a live board. Heavy files if you fake a dashboard in vectors.

Use for: the six-stop fleet diagram as a 4 s loop. Source the layout from how-the-fleet-works.html.

### Rive

URL: https://rive.app/blog/rive-as-a-lottie-alternative

What: `.riv` binary with state machines. Inputs can be data. Duolingo cut file size about 15x vs Lottie on characters.

Pros: a verify dot can be an input. Red / amber / green as states, not three movies. GPU, small.

Cons: new editor. Overkill for a one-shot film.

Use for: the workbench status dot, wired later to real state. Not this round.

### Pick

Film the canvas and the board with Screen Studio. Rebuild the gate with vhs. Keep `.cast` files of real verifies for nerds who want to copy the command. Animate the six-stop diagram in Rive if it must react. Skip Lottie unless someone already has the AE file.

## Live metrics without shouting

What the good ones do:

1. One number, tabular lining, no "incredible." Stripe BFCM, Higgsfield about, Vercel changelog "64% faster."
2. Color is state, not decoration. Workbench already: red blocked, amber stalled, green passed, grey missing. Keep that map.
3. The header paints the worst state. workbench.html `.top.state-red` already does this. NASA walls and Bloomberg do the same.
4. Sparklines beat paragraphs. Linear's fake spreadsheet on https://linear.app/change is a joke that still reads as data. A 24-hour cost sparkline on the hub would be enough.
5. Motion is the update, not a loop for its own sake. Counters tick. Dots pulse only when red or amber. workbench.html already gates the pulse behind `prefers-reduced-motion`.
6. No three KPI cards in a row. That is the AI-template tell. Put the numbers in the chrome, like Vercel Speed Insights and the workbench `.headpills`.
7. Live beats fake. Stripe opened real load. If a number cannot be live, make it a dated still and say the date.

For the hub: reuse workbench pills. Lanes, models, verify, cost. Do not invent a second dashboard.
