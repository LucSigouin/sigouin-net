## 12 mechanics that separate award sites from templates

Each mechanic: what it is, two live URLs, how to build it in plain HTML/CSS/JS or Three.js. No framework required.

### 1. Scroll is a camera, not a page

The wheel advances a timeline. Sections pin. The camera dollies. Copy is sparse because the move is the sentence.
Examples: https://landonorris.com/ , https://terminal-industries.com/
Build: one tall `main`. Each scene is a `section` with `min-height: 100vh`. Listen to `scroll`. Map `scrollY / (scrollHeight - innerHeight)` to 0..1. Drive CSS `--t` or a Three.js camera along a curve. `position: sticky` on the visual, content slides over it. Lenis is optional. `overflow` plus `requestAnimationFrame` is enough.

### 2. Custom cursor that becomes the UI

The default arrow dies. A small mark follows the pointer and grows into a label, a circle of video, or a magnet.
Examples: https://cuberto.com/ , https://basement.studio/
Build: a `div` with `position: fixed; pointer-events: none; mix-blend-mode: difference`. On `pointermove`, lerp `x,y` toward `clientX,clientY`. On `[data-cursor="play"]` hover, scale up and swap inner text. Never hide the real cursor until the custom one has moved once, for a11y.

### 3. WebGL as weather, not a circus

3D sits behind type. Lighting, particles, a slow object. If you screenshot it, the type still holds.
Examples: https://minhpham.design/ , https://iventions.com/
Build: a full-viewport `canvas` with `position: fixed; z-index: 0`. Three.js `Scene`, one mesh, a dim light. Content in a `div` with `position: relative; z-index: 1; pointer-events: none` except on links. Pause the renderer when `document.hidden` or when `prefers-reduced-motion: reduce`.

### 4. Transitions that do not cut

Leaving a project is a continuation. Shared element, wipe, or shader crossfade. The site feels like one file.
Examples: https://romanjeanelie.com/ , https://by-kin.com/
Build: intercept link clicks. `document.startViewTransition(() => { location.href = url })` in supporting browsers. Fallback: fade the current view, then swap. For a still that becomes the next hero, give both images the same `view-transition-name`.

### 5. Hover that plays the work

A still is a lie. Hover or focus starts a muted loop. Click opens the live thing.
Examples: https://immersive-g.com/ , https://cuberto.com/
Build: `<video muted loop playsinline preload="none" poster="still.jpg">`. On `pointerenter` and `focus`, `video.play()`. On leave, `pause()` and reset `currentTime`. Keep files under a few MB. One playing video at a time.

### 6. Sound you opt into

A click-to-enable control. Music or Foley that makes the world real. Never autoplay.
Examples: https://leoparpeix.com/ , https://messenger.abeto.co/
Build: one button, `AudioContext` resumed on click. HTMLAudio or a Three.js positional source. Persist `localStorage.sound = on|off`. Mute on `visibilitychange`. Show a speaker, not a paragraph.

### 7. Kinetic type as the hero

Letters are the graphic. They split, stretch, reassemble. Reading still works.
Examples: https://matvoyce.com/ , https://corentinbernadou.com/
Build: split a headline into `<span>` per char. On scroll, `translateY` and `skewY` from a sine of progress. Or use GSAP SplitText if you already have it. Keep a `prefers-reduced-motion` branch that shows the full word static.

### 8. A world you can drive or walk

The CV is a place. Physics or a character controller. Projects are props.
Examples: https://bruno-simon.com/ , https://messenger.abeto.co/
Build: Three.js scene, a floor, a camera on a simple vehicle or WASD character. Raycast on click to open a project. Cannon or a homemade AABB is enough for a hub of 12 objects. Provide a list fallback for mobile and reduced motion.

### 9. Filmstrip / horizontal rail

Work sits in a row you scrub. Vertical scroll maps to horizontal travel.
Examples: https://lusion.co/ featured stack, https://www.scoutmotors.com/
Build: a `div` with `display: flex; overflow: hidden`. On scroll through a sticky viewport, set `transform: translateX(progress * -1 * (trackWidth - viewportWidth))`. Snap to slides with `scroll-snap` as the no-JS path.

### 10. Uneven index, never three equal cards

Award indexes are numbered lists, huge stills, or filterable rows. They are not a 3-column card grid with identical heights.
Examples: https://leoparpeix.com/ , https://basement.studio/ showcase, https://www.rejouice.com/work
Build: an `ol`. Each `li` is a full-width row: number, name, year, one still that only appears on hover. CSS grid with `grid-template-columns: 4rem 1fr 8rem` beats `repeat(3, 1fr)`.

### 11. A live number on the page

A counter, a clock, a savings figure, a view count. Proof the thing runs.
Examples: https://terminal-industries.com/ ROI block, https://www.joshwcomeau.com/ view counts
Build: `fetch('/api/status')` every 30s. Write the number into a `data-count` node. Animate with an easing step from old to new. If the API fails, keep the last number and dim it. Never fake the digit.

### 12. Reduced motion and a still that still works

Jurors freeze the page and throttle the CPU. If the still is ugly, the motion was hiding it. If 4x CPU drop kills 60fps, it will not win.
Examples: https://www.hontran.dev/blog/best-award-winning-websites-2026 criteria, https://www.14islands.com/ a11y-aware WebGL
Build: `@media (prefers-reduced-motion: reduce) { * { animation: none !important; transition: none !important; } }` plus a JS guard that never starts Three.js. Test with DevTools CPU 4x. Cap pixel ratio at 1.5. Stop the loop when the canvas is offscreen.

## Anti-list: 10 tells of an AI-generated site

### 1. Purple gradient hero on a dark field

The default model look. Fix: pick one real pigment from a photo Luc already owns. Flat fill or a grain overlay. No `linear-gradient(135deg, #667eea, #764ba2)`.

### 2. Three equal cards under "Featured work"

Template rhythm. Fix: one huge still, then a numbered list. Or a 12-column grid with projects spanning 7, 5, 12, 4, 8.

### 3. Generic hero copy

"Crafting digital experiences that matter." "Welcome to my portfolio." Fix: no hero sentence. A name, a still, a live object. If you need words, use a fact: "12 projects. Ottawa. Running."

### 4. Inter, Poppins, or Space Grotesk on everything

The font stack of generated UI. Fix: one paid or foundry face with a job. Pangram Pangram exists for this. Pair with a mono for data. Never four weights of a Google default.

### 5. Glassmorphism, rounded-2xl, soft shadows, floating orbs

The shadcn-plus-blob look. Fix: hard edges or none. One radius used twice, not on every card. No blur sandwich.

### 6. A 3D blob or knot as the hero with no subject

Decoration pretending to be craft. Fix: a model of a real shipped thing. A router. A cartridge. A course pin. A canvas node. If it is not a thing Luc built, do not put it in WebGL.

### 7. Icon row of six services

"Design / Develop / Deploy / Scale / Innovate / Empower" with Lucide icons. Fix: delete the services section. The work is the services.

### 8. Centered max-width column in a sea of background

The Claude artifact page. Luc already banned this. Fix: full-bleed bands. Grids that use the window. Padding with `clamp`, not `margin: 0 auto` on the whole page.

### 9. Fake screenshots and stock faces

Unsplash laptops, generated UI mockups. Fix: real captures from the running apps. If a project has no still, record a 4-second silent loop. Do not invent a UI.

### 10. Logo cloud, infinite marquee, emoji headings

Motion used to hide empty content. Fix: if a name matters, typeset it once, still. Headings in words, not icons.

## How the best sites present live data and running apps

They do not screenshot a dashboard and call it live. They put a live node on the page.

**Embed the real app.** An iframe of a public URL, sandboxed, with a poster still until the iframe paints. Use this for Undergrowth, teetimes, livetvcan marketing. Always a still first. The iframe is a reward, not the LCP.

**Playable clone, not the production box.** Bruno and Messenger are this. A small Three.js or canvas build that is the product reduced. Safer than iframing admin tools. Use this for the CNVS canvas: a schematic that moves, not a live login.

**API-fed counters.** Terminal Industries puts a dollar figure on the page that updates as you tweak inputs. Josh Comeau stores view counts in Postgres and prints them. basement.studio prints "Showcase (26)" as a live inventory number. For Luc: Worker request counts, teetimes open slots today, homelab disk free, last deploy time. Fetch JSON. Render one number in the same type as the title. Dim it if stale.

**Status as material.** A row of dots or a ticker that is actually uptime. Not a Statuspage iframe unless the design is restyled. Poll `/health`. Map to color. Keep it one line.

**Console cosplay only if it is real.** Cerebrium and USAvionix feel like products because the site is adjacent to the console. A fake terminal with typed lorem is an AI tell. A real `curl` output from last deploy is not.

**Do not iframe anything private.** Homelab UIs stay out. Pull a read-only number Luc already publishes, or a public Pages URL.

## How they present 3D on the web

Three tools. Pick by weight.

**model-viewer.** A web component. Drop a GLB. Orbit, AR, hotspots. No scene graph to maintain. Good for one object on a panel. Live docs: https://modelviewer.dev/

**Three.js and a GLB.** Full control. Character, lighting, post. Needed for a world, a car, a planet. Bruno, Messenger, Lusion, Iventions, Active Theory.

**Spline.** Visual editor, embed a scene. Fast for a designer pass. Less control, extra runtime. Live: https://spline.design/

Five live examples:

1. Bruno Simon, https://bruno-simon.com/ . Three.js world. The model is a place. Fallback needed for phones that cannot drive it.
2. Messenger, https://messenger.abeto.co/ . Three.js character on a planet. WebSockets hint at shared presence. The GLB is the site.
3. Opal Tadpole, https://op.al/ . Product as a tiny 3D object you inspect. Closest to what `<model-viewer>` is for.
4. Iventions, https://iventions.com/ . Three.js lighting as museum spots. Projects are objects in a dark room.
5. Spline editor itself, https://spline.design/ . Proof that a 3D file can be the homepage. Use only if Luc wants to author scenes without writing a renderer.

Rule: one 3D context per page if you can. Pause offscreen. Cap DPR. Offer a still. A GLB of a real object beats a generated sculpture.

## Three site structures for ~12 projects plus "how I work"

### Structure A. The long film
