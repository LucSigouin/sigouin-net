LiveLane heartbeats, from file mtimes

One row per lane directory under sigouin-net/fleet-r*/ plus this workbench. The heartbeat is the newest modification time of that lane's REPORT.md or result.json. A lane whose task is still working and whose heartbeat is older than 10 minutes reads stalled. A lane with no heartbeat file at all, or with no task in the ledger, is shown as exactly that and is never left out: that is how an untracked two-step kimi spawn stops being invisible.

A lane is joined to a task only when its full path appears in exactly one worker prompt file. Where two or more prompts mention the path, the join is ambiguous and this page says so rather than guessing.
