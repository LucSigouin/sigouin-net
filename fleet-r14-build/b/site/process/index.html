How it runs

8 stops 1 orchestrator, never a writer 13 tools and models named below 0 untested gates

P1 / The canvas

Workers are windows, not hidden threads

Every agent runs as a visible terminal node on a CNVS canvas. Luc can read a worker mid sentence, interrupt it, or let it finish. Nothing runs where he cannot see it.

  • CNVS
  • cnvsctl
  • Tracked tasks
  • Shared canvas memory

P2 / The split

One prompt becomes five folders

The orchestrator is always Claude Fable 5, and it never edits a file. It writes the rubric first, cuts the work into lanes that touch no shared file, and hands each lane to a fresh worker: Claude Opus 5, Codex, Grok 4.6, Kimi K3 or Qwen.

  • Claude Fable 5
  • Claude Opus 5
  • Codex
  • Grok 4.6
  • Kimi K3
  • Qwen

P3 / The gate

Red first, on purpose

Done means a worker reported and its verify command exited zero. Before a gate is trusted it is broken on purpose to prove it can fail. A suite that has never gone red has proven nothing.

  • Mutant tested gates
  • Read only predicates
  • result.json contract

P4 / The board

The header colour is the fleet state

One HTML page, live from the first spawn: every worker, its task, its model, its verify command and what it cost. Not a diary written afterwards. The model comes from each worker's own result.json, because the task ledger has no model field.

  • workbench.html
  • 131 REPORT.md on disk
  • 66 result.json

P5 / The contest

Nine lanes, one brief, one winner

The largest contest on disk ran nine lanes across four model families on a single landing brief. No agent scores another agent. Luc picks by eye, and the eight that lose are archived with a revive note, never deleted.

  • Claude Opus 5
  • Codex
  • Grok 4.6
  • Kimi K3

P6 / Same brief, two models

9.25 against 8.42

Two workers get the identical brief and the identical rubric, in folders that never touch. Claude Opus 5 above, Kimi K3 below. The gap is visible before anyone reads a score, which is the whole reason the lanes are rendered side by side.

  • Claude Opus 5
  • Kimi K3
  • Disjoint folders
  • One rubric

P7 / The overnight lab

Rounds land while the house sleeps

Art and layout rounds run unattended and log their own cost. 146 images, 30.25 USD, generated by gpt-image-2, kie.ai Nano Banana, Higgsfield Seedance and Tripo for anything that had to turn in three dimensions. References come from MotionSites and 21st.dev.

  • gpt-image-2
  • kie.ai
  • Higgsfield
  • Tripo
  • MotionSites
  • 21st.dev

P8 / The shelf

Four archived, one shipped

Losing work goes to archive intact, with a row explaining why and how to revive it. Nothing is thrown away, and nothing rejected gets pitched twice. The winner deploys through its own script, then the served hash is compared against the local one before anyone says it is live.

  • Archive with revive notes
  • deploy.sh only
  • Served hash equals local
